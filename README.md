# cpp-basics

My C++ learning journey, from the first line of code onward. Everything here is written by me while learning, so expect simple programs and steady progress.

## What's inside

| Topic | What I practiced |
|-------|------------------|
| Basics | Syntax, input/output, loops (`for`, `while`), conditions |
| Functions | Writing and calling functions, passing arguments |
| Structs | Grouping related data together |
| OOP | Classes, objects, static members |

## Mini projects

- **BMI Calculator** – takes height and weight, then tells you the BMI.
- **Arithmetic Calculator** – does basic math operations on two numbers.
- **Bank Account Class** – a small program that uses a class to deposit, withdraw and check balance.
